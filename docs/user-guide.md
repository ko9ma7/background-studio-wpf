# Background Studio C# WPF 1.3 사용 설명서

## 1. 설치와 첫 실행

1. GitHub Releases의 `BackgroundStudio-WPF-v1.3.0-win-x64.zip`을 받습니다.
2. ZIP을 새 폴더에 완전히 풉니다.
3. `BackgroundStudio.exe`를 실행합니다.
4. 처음 한 번 `모델 준비`를 눌러 U2NetP 모델을 받습니다.

Windows가 게시자를 확인할 수 없다고 표시할 수 있습니다. 이 공개 배포본은
코드 서명 인증서를 사용하지 않습니다. GitHub Release의 `.sha256` 값과 받은
ZIP의 SHA-256을 비교한 뒤 실행하세요.

## 2. 파일과 대기열

- `이미지 추가`, `동영상 추가`: 여러 파일을 한 번에 대기열에 넣습니다.
- 파일을 `BackgroundStudio.exe`로 끌어 놓아 시작해도 대기열에 추가됩니다.
- `선택 삭제`: 잘못 추가한 한 항목만 제거합니다.
- `전체 초기화`: 대기열, 결과 목록, 미리보기를 새 작업 상태로 되돌립니다.
- `대기열 전체 변환`: 대기 상태인 항목을 위에서 아래로 순차 처리합니다.
- `작업 취소`: 현재 작업을 안전하게 중지합니다.

## 3. 배경과 전문 편집

- `배경`: 투명, 단색, 다른 이미지, 원본 블러와 그림자를 설정합니다.
- `필터·외곽`: 일반 보정부터 코믹 하이라이트, 연필선, 마스크, 외곽선,
  SVG 패스용 값을 설정합니다.
- `위치·크기`: 피사체 자동 중앙 정렬, 크기, X/Y, 회전, 반전, 캔버스를
  설정합니다.
- `고급`: 밝기, 대비, 채도, 색온도, 색조, 불투명도와 마스크 경계를
  조절합니다.
- `저장·결과`: 출력 폴더와 이미지·동영상 형식을 고릅니다.

## 4. 히스토리로 원본 비교

처음 분리한 뒤 편집값을 바꾸면 미리보기 아래에 히스토리 칩이 생깁니다.
각 상태는 처리된 직전 화면이 아니라 같은 분리 원본에 다시 적용됩니다.
원하는 칩을 클릭하면 미리보기와 모든 조절값이 함께 복원됩니다.

히스토리는 작업 항목별 최대 24개이며 앱을 닫으면 사라집니다. 선택한 상태를
파일로 남기려면 `대기열 전체 변환`을 다시 누르세요.

## 5. 저장과 결과 찾기

기본 출력 폴더는 Windows `사진\Background Studio`입니다. 처리가 성공하면
자동 저장되고 아래 결과 목록에 파일이 남습니다. `출력 폴더 열기`와 `선택
결과 열기`로 바로 확인할 수 있습니다.

- 이미지: PNG, JPEG, BMP, TIFF, SVG
- 투명 영상: WebM VP9, MOV ProRes 4444
- 일반 영상: MP4 H.264, WebM, MOV, GIF

투명도를 지원하지 않는 JPEG·BMP·MP4를 선택하면 앱은 투명 영역을 선택한
배경으로 합성합니다.

## 6. FFmpeg 안내

FFmpeg는 배경 제거 AI가 아니라 동영상 프레임 추출, 오디오 유지, 최종 영상
인코딩을 담당하는 미디어 도구입니다. `FFmpeg 준비` 또는 첫 동영상 처리 때
앱이 검증된 ZIP을 자체 폴더에 내려받습니다. 시스템 PATH, 관리자 권한,
수동 설치가 필요하지 않습니다.

## 7. 문제 해결

- 모델 준비 실패: 인터넷 연결과 보안 프로그램의 다운로드 차단을 확인합니다.
- 영상 준비 실패: 앱을 다시 열고 `FFmpeg 준비`를 누릅니다.
- 투명 WebM이 검게 보임: 알파 지원 편집기에서 확인하거나 MOV를 사용합니다.
- 긴 영상이 느림: 짧은 구간에서 모델·프레임·가장자리 값을 먼저 검증합니다.
- 머리카락·유리·연기: 마스크 기준, 부드러움, 확장/축소 값을 미세 조정합니다.
