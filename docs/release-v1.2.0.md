# Background Studio WPF 1.2.0

## 핵심 변경

- 여러 이미지·동영상을 순차 처리하는 작업 대기열
- 선택 삭제, 전체 초기화, 재대기, 취소와 완료 결과 목록
- 저장 대화상자 대신 앱 출력 폴더 자동 저장
- 출력 폴더와 선택 결과 바로 열기
- 상단 탭 기반 배경·외곽·위치·고급·저장 편집
- 색 보정, 마스크 확장/축소, 회전·반전, 캔버스 비율, 12종 필터
- FFmpeg 8.1.2 자동 다운로드·SHA-256 검증

## 충돌 수정

Windows 셸 확장 프로그램이 함께 로드되는 저장 대화상자에서 발생하던
네이티브 `0xc0000409` 종료를 피하도록 처리 완료 시 저장 대화상자를 열지
않습니다. 결과는 지정 출력 폴더에 자동 저장되고 앱 안의 결과 목록에 남습니다.

## 확인 결과

- Release 빌드 경고 0, 오류 0
- 편집 엔진 테스트 6개 통과
- 실제 창에서 5개 편집 탭 전환 확인
- 창 닫기 후 새 Application Error/WER 이벤트 없음
