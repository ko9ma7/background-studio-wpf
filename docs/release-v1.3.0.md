# Background Studio WPF 1.3.0

## 주요 변경

- 선택 작업별 비파괴 편집 히스토리
- 분리 원본에서 필터·위치·색·마스크를 다시 계산하는 비교 미리보기
- 최대 24개 편집 상태와 중복 상태 억제
- 히스토리 클릭 시 전체 편집값과 배경 경로 복원
- 실행 파일로 이미지·동영상을 끌어 놓거나 경로 인수로 여는 시작 흐름
- 사용 설명서와 세 버전 선택 안내

## 확인한 동작

- 이미지 배경 제거와 자동 저장
- 코믹 하이라이트, 흑백, 분리 원본 상태 전환
- 히스토리 선택 후 중복 기록 없이 재저장
- Release 빌드와 8개 단위 테스트

## 설치

`BackgroundStudio-WPF-v1.3.0-win-x64.zip`을 내려받아 압축을 푼 뒤
`BackgroundStudio.exe`를 실행합니다. .NET 런타임과 FFmpeg 수동 설치는
필요하지 않습니다. 함께 배포한 `.sha256`으로 ZIP 무결성을 확인할 수
있습니다.

코드 서명 인증서를 사용하지 않아 Windows SmartScreen 경고가 표시될 수
있습니다.
