# Background Studio WPF 1.4.0

## 새 기능

- 세로·대형 이미지 기본 맞춤 보기
- 포인터 중심 휠 줌, 손 도구 팬, 100% 실제 픽셀 보기
- 남은 배경 지우기, 피사체 복원, 브러시 크기, 마스크 실행 취소

## 수정

- 편집 히스토리를 미리보기 위가 아닌 별도 행에 배치해 이미지 아래가
  가려지지 않습니다.
- 신규·오류·편집 변경·명시적 재대기 작업만 다음 일괄 변환에서 실행합니다.
- 수동 마스크는 원래 AI 알파에서 매번 재생해 복원 결과가 누적 손상되지
  않습니다.

수동 브러시는 이미지 작업용입니다. 동영상은 자동 마스크 후처리 값을
사용합니다.
