# 전문 편집 파이프라인

이 앱의 편집값은 배경 제거 모델이 만든 **알파 마스크와 피사체 외곽**을
기준으로 계산한다. 피사체의 실제 바운딩 박스를 찾은 뒤 마스크 임계값·
페더·확장/축소, 중앙 정렬, 배율, X/Y 위치, 회전·반전, 색 보정, 출력
레이어, 캔버스, 배경과 그림자 순서로 적용한다.

`완성 합성`은 일반 결과, `흑백 마스크`는 편집기 전달용 채널, `외곽선만`은
투명 라인 레이어다. 코믹 필터의 내부 선은 RGB 명암 경계, 외곽선 레이어는
알파 경계에서 각각 계산하므로 함께 써도 역할이 겹치지 않는다.

## 권장값

| 목적 | 마스크 기준 | 부드러움 | 외곽선 | 배율 | 추천 출력 |
|---|---:|---:|---:|---:|---|
| 상품 사진 | 0.45~0.60 | 0.08~0.18 | 1~3px | 90~110% | PNG |
| 인물·머리카락 | 0.35~0.50 | 0.15~0.30 | 1~2px | 90~105% | PNG |
| 스티커 | 0.50~0.65 | 0.05~0.15 | 4~8px | 80~100% | PNG/SVG |
| 코믹 하이라이트 | 0.45~0.60 | 0.08~0.20 | 2~5px | 90~120% | PNG/MP4 |
| 편집기 전달용 마스크 | 0.45~0.60 | 0.05~0.15 | 해당 없음 | 100% | PNG/TIFF |

`고급` 탭의 밝기·대비·채도는 100%가 원본이다. 색온도·색조·불투명도는
피사체에만 적용된다. `필터·외곽` 탭에서는 원본 외에 밝게, 선명하게, 웜,
쿨, 흑백, 코믹, 고대비, 포스터, 세피아, 반전, 연필선을 선택할 수 있다.
인쇄·후편집 작업은 마스크와 외곽선을 각각 저장해 원본과 함께 보관한다.

가로·세로 위치는 캔버스 대비 -50~50%다. 자동 중앙 정렬은 매 프레임의
마스크 중심을 사용하므로 피사체 크기가 급변하는 영상은 먼저 짧은 구간으로
움직임을 확인한다.

## 저장과 FFmpeg

- 이미지: PNG, JPEG, BMP, TIFF, 외곽 SVG
- 투명 영상: WebM VP9, MOV ProRes 4444
- 일반 영상: MP4 H.264, WebM, MOV, GIF

FFmpeg는 AI 모델이 아니라 영상을 프레임으로 풀고 결과와 오디오를 다시
컨테이너에 묶는 미디어 엔진이다. 상단 `FFmpeg 준비`를 누르거나 동영상
처리를 시작하면 Gyan FFmpeg 8.1.2 Essentials ZIP을 내려받고 SHA-256을
검증한 뒤 `%LOCALAPPDATA%\BackgroundStudio\ffmpeg`에서 실행한다. 시스템
PATH 설정과 관리자 권한은 필요하지 않다.

SVG는 알파 외곽을 벡터 경로로 내보내지만 펜 도구의 베지어 핸들을 직접
편집하는 기능은 아니다. 인쇄·로고용 최종 패스는 전문 벡터 편집기에서
마지막 노드를 정리하는 것이 안전하다.
